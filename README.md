# Basket Random 2P — Пиксельный физический баскетбол

Аркадная 2D-игра в стиле **Basket Random** для двух игроков на одном компьютере (или против ИИ-бота) с физикой шатающихся баскетболистов, высокими прыжками, честными столкновениями мяча и случайными модификаторами после каждого забитого гола.

---

## Требования

- **Node.js** версии `18.x` или выше (рекомендуется `20+`)
- **npm** (устанавливается вместе с Node.js)

---

## Быстрый старт (Как запустить локально)

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Запустите сервер для разработки:**
   ```bash
   npm run dev
   ```

3. **Откройте игру в браузере:**
   Перейдите по адресу:
   ```text
   http://localhost:3000
   ```

---

| Команда | Описание |

## Управление в игре

- **Игрок 1 (Желтая команда слева):**
  - Зажать **`W`** или **`Пробел` (`Space`)** — оба игрока команды прыгают в сторону текущего наклона и поднимают руки.
  - Отпустить **`W`** или **`Пробел`** — бросить мяч в кольцо соперника (или опустить руки, если мяча нет).
- **Игрок 2 (Синяя команда справа):**
  - Зажать **`Стрелку вверх` (`↑`)** — прыжок обоих игроков команды и подъем рук.
  - Отпустить **`Стрелку вверх` (`↑`)** — бросок мяча в кольцо.
- **Мышь / Сенсорный экран:** можно зажимать и отпускать кнопки **`Зажать: W / Пробел`** и **`Зажать: ↑ Стрелка`** в нижних углах экрана.
- **Пауза:** клавиша **`Esc`** или кнопка **`||`** в правом верхнем углу.

---

## Особенности игры

- **2 режима игры:** локальный матч **2 Игрока** на одной клавиатуре или **1 Игрок против Бота**.
- **Физика маятника:** персонажи постоянно раскачиваются вперед и назад — направление прыжка зависит от того, в какую сторону наклонен баскетболист в момент нажатия.
- **Матч до 5 очков** со статистикой бросков, перехватов и блок-шотов.
- **Случайные события после каждого гола:** *Огромные кольца*, *Длинные руки*, *Тяжелый железный мяч*, *Пляжный прыгучий мяч*, *Скользкий паркет*, *Высокий прыжок* и *Снайперские кольца* (можно переключить на режим «Только классика» в меню).
